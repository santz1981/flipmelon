# Security policy

## Reporting an issue

Please avoid publishing exploit details, personal Android device identifiers, ADB keys, tokens, or other sensitive data in public GitHub Issues.

Prefer GitHub's **Private vulnerability reporting** when enabled on this repository (Settings → Security → Code security). If it has not been enabled, ask the maintainer for a private reporting channel without disclosing details publicly.

## Safe usage

- USB debugging grants sensitive access. Only authorize computers you trust and revoke stale authorizations on your Android phone.
- Flipmelon currently distributes unsigned Windows builds; a security block is not permission to disable Smart App Control or other Windows protections.
- Release packages should link to a specific GitHub tag and include checksums and applicable third-party license notices.
