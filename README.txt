INTER — fonte oficial da interface Flipmelon

Para garantir Inter em computadores que nao tem a fonte instalada, coloque aqui
os arquivos TTF/OTF oficiais da familia Inter antes de executar build-windows.bat.
O aplicativo carrega esses arquivos automaticamente na inicializacao; eles sao
empacotados junto com assets/ pelo PyInstaller. Essa pasta nao inclui fontes.

Obtenha a fonte Inter em https://rsms.me/inter/ ou
https://fonts.google.com/specimen/Inter

Respeite a licenca SIL Open Font License 1.1 ao redistribuir a fonte. Inclua
um arquivo OFL.txt no pacote se decidir distribuí-la; consulte os termos
exatos do arquivo obtido.

Sem esses arquivos, o app usa Inter se instalada no computador; se nao estiver,
usa Segoe UI (Windows) ou DejaVu Sans (Linux) como fallback.
